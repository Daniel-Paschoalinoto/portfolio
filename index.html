Projetos

ECO - Fragmento do Amanhã

Tecnologias: Node.js + Windows Terminal
Projeto de férias: um jogo narrativo para Windows que utiliza Node.js e PowerShell para manipular o terminal, criando uma experiência imersiva e interativa em uma interface de texto.

A narrativa aborda temas como inteligência artificial, controle neural e utopias futuristas, tudo apresentado em um estilo único de ficção terminal.

Ao longo do desenvolvimento, explorei as principais etapas da criação de um jogo, incluindo definição de enredo, distribuição, design de mecânicas, criação da engine, configuração de ambiente, licenciamento, testes, narrativa, comunicação e promoção. Também retomei habilidades em edição de vídeo e áudio para complementar o projeto.

Pokémon

Tecnologias: HTML + CSS + JavaScript
Projeto desenvolvido para treinar consumo de APIs e manipulação de dados no frontend, de forma leve e divertida.

A aplicação exibe os 151 Pokémons da primeira geração, trazendo sprites animados e o som característico (cry) de cada um, tudo consumido diretamente da PokeAPI.

Os cards são dinâmicos, interativos e responsivos, com animações sutis e feedback visual ao passar o mouse ou clicar, proporcionando uma experiência agradável e intuitiva.

MonsterFriends

Tecnologias: React + Vite
Esta aplicação foi desenvolvida como parte de uma atividade prática no curso da escola canadense ZTM, com o objetivo de consolidar meus conhecimentos em React e no ecossistema moderno do Vite.
